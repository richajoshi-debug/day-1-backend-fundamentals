# Day 1 – Backend Fundamentals, Web & API Basics 🚀

Day 1 was all about understanding what happens behind the scenes when we use a website or an application.

I focused on learning how the frontend communicates with the backend, how requests travel across the web, and how APIs help applications exchange data.

## 📚 Topics Covered

- **Frontend vs Backend:** Understanding the responsibilities of the frontend and backend and how they work together.
- **Client–Server Architecture:** Learning how a client sends requests and how a server processes them and returns responses.
- **How the Web Works:** Understanding the basic flow of DNS → HTTP Request → Server Processing → HTTP Response.
- **HTTP Methods & Status Codes:** Learning methods like GET and POST, along with common status codes such as 200, 201, 400, 404, and 500.
- **REST API Fundamentals:** Understanding endpoints, requests, responses, and how REST APIs allow applications to communicate.
- **API Versioning Basics:** Understanding why APIs use versions and how versioning helps maintain compatibility.
- **HTTPS & Backend Trust Boundaries:** Learning why secure communication matters and why the backend must validate and verify incoming requests instead of blindly trusting client data.

## 🛠️ Hands-on Practice

### 1. Inspecting API Calls Using Browser DevTools
- Opened Chrome DevTools and explored the Network tab.
- Inspected API requests and responses.
- Observed HTTP methods, status codes, and response data.

### 2. Calling Public APIs Using Postman
- Created and sent a GET request to a public API.
- Used JSONPlaceholder to retrieve sample post data.
- Explored the response returned by the server.

### 3. Building a Simple API Using FastAPI
- Set up a Python virtual environment.
- Installed FastAPI and Uvicorn.
- Created GET and POST endpoints.
- Used Pydantic for request-body validation.
- Tested the endpoints using Swagger UI.

## 🎯 Day 1 Outcome

By the end of Day 1, I developed a basic understanding of how a request travels from a client to a backend server and how the server processes that request and sends a response back.

I also got hands-on experience inspecting API calls, testing public APIs, and building a simple backend API using FastAPI.
